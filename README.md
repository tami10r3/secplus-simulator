# Security+ SY0-701 Exam Simulator

A free, browser-based practice exam simulator for CompTIA Security+ (SY0-701).

- 8 full-length practice exams (76 questions each: 5 performance-based questions + 71 multiple choice)
- 90-minute timer, flag for review, item review screen
- PBQ types: firewall rules, log analysis, drag-and-drop network placement, click-to-investigate incidents, terminal output, matching, and ordering
- Estimated 100–900 scaled score weighted by the official domain percentages, plus a strict PBQ score
- Confidence tagging and a weak-area exam built from your own results
- Progress is saved in your browser only; nothing is sent to a server
